# Changelog

## 0.1.0 (unreleased)

First usable version. Name, file extension, command and keyword spellings may
still change.

- Variables, constants, conditions, loops, functions and closures.
- Lists, dictionaries and string indexing.
- Built-ins: `bolo`, `suno`, `lambai`, `joro`, `nikalo`, `sankhya`, `shabd`,
  `prakar`.
- Bilingual diagnostics with codes, locations and suggestions.
- `hinglish run`, `hinglish check` and a REPL.
