# 5. English and Hindi website

Status: accepted

## Decision

The site is built once per locale under `/en` and `/hi`, from typed dictionaries
in `apps/docs/lib/i18n`, with no i18n library: a static export has no middleware,
and the type of the English dictionary makes a missing Hindi string a compile
error. Hindi is written in Devanagari. Keywords, built-ins, names, error codes
and the product name stay in Roman script.

`core` carries a third text, `deva`, in every diagnostic, selected with
`lang: 'deva'`. The command line still offers only `en` and `hi`, and its output
is unchanged.

## Consequences

Every new message, page string and section of `docs/language-spec.md` or
`docs/error-codes.md` needs a Hindi counterpart; `docs/hi/` holds the latter.
