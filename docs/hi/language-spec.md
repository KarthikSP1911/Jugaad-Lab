# भाषा विनिर्देश v0.1 (मसौदा)

भाषा का नाम, फ़ाइल एक्सटेंशन (`.hing`), CLI कमांड (`hinglish`) और कीवर्ड की
वर्तनी तब तक अस्थायी हैं जब तक स्वामी उनकी पुष्टि नहीं कर देता।

## डिज़ाइन के सिद्धांत

1. **हर कीवर्ड एक शब्द।** कई शब्दों वाले कीवर्ड आसानी से टूटते हैं (दोष 10)। इसके बजाय Hinglish व्याकरण में दो एक-शब्द वाले टोकन से `else if` बनाती है।
2. **प्रोग्राम का कोई बाहरी ढाँचा नहीं।** Hinglish सबसे ऊपरी स्तर के स्टेटमेंट सीधे चलाती है।
3. **जानी-पहचानी बनावट।** ब्लॉक के लिए ब्रेस, शर्त के चारों ओर कोष्ठक और अंत में `;`, ताकि त्रुटि के बाद `;` से दोबारा संभला जा सके।
4. **जहाँ गलती पकड़ी जा सके, वहाँ सख्ती।** अघोषित नाम, स्थिरांक को बदलना, आर्ग्युमेंट की गलत गिनती और बूलियन से अलग शर्त त्रुटियाँ हैं, चुपचाप कुछ न करने वाली बातें नहीं।
5. **हर कीवर्ड की एक मानक वर्तनी।** रोमन हिन्दी की कोई मानक वर्तनी नहीं है (`jhooth`, `jhuth`; `wapas`, `vapas`)। लेक्सर कीवर्ड एक तालिका से पढ़ता है, इसलिए पार्सर को छुए बिना दूसरी वर्तनियाँ उपनाम के रूप में जोड़ी जा सकती हैं।

## कीवर्ड

| अवधारणा | कीवर्ड |
| --- | --- |
| वेरिएबल / स्थिरांक | `rakho` / `pakka` |
| फ़ंक्शन / लौटाना | `kaam` / `wapas` |
| अगर / वरना | `agar` / `warna` (`warna agar` दो टोकन हैं) |
| सच / झूठ / खाली | `sach` / `jhooth` / `khaali` |
| जब-तक लूप / गिनती वाला लूप | `jabtak` / `chalo (init; test; step)` |
| लूप तोड़ना / अगला चक्कर | `ruko` / `agla` |
| और / या / नहीं | `aur` / `ya` / `nahi` (`&&`, `\|\|`, `!` के उपनाम) |

`bolo` और `suno` अंतर्निहित फ़ंक्शन हैं, कीवर्ड नहीं। आरक्षित शब्दों में छोटे-बड़े
अक्षर का फ़र्क होता है और उन्हें पहचानकर्ता की तरह इस्तेमाल नहीं किया जा सकता।

## शब्द-स्तर के नियम और टाइप

- **पहचानकर्ता:** एक अक्षर या `_`, उसके बाद अक्षर, अंक या `_`। Unicode के अक्षर, अंक और मात्राएँ (`ID_Start`, `ID_Continue`) मान्य हैं, इसलिए देवनागरी नाम भी चलते हैं।
- **संख्याएँ:** बिना चिह्न के दशमलव लिटरल (`42`, `3.14`)। आगे लगा `-` हमेशा एकल या द्वि-आधारी ऑपरेटर होता है, जिससे दोष 1 ठीक होता है।
- **स्ट्रिंग:** `"..."` या `'...'`, एस्केप `\n \t \\ \" \'` के साथ। MVP में स्ट्रिंग एक से ज़्यादा लाइनों में नहीं फैल सकती।
- **टिप्पणियाँ:** `// line` और `/* block */`।

| टाइप | लिटरल | टिप्पणी |
| --- | --- | --- |
| number | `42`, `3.14` | 64-बिट फ़्लोट; `/` हमेशा दशमलव वाला भाग है |
| string | `"namaste"` | अपरिवर्तनीय; कोई भी एक पक्ष स्ट्रिंग हो तो `+` जोड़ता है |
| boolean | `sach`, `jhooth` | शर्तों में सिर्फ़ यही मान चलते हैं |
| null | `khaali` |  |
| list | `[1, 2, 3]` | परिवर्तनीय, इंडेक्स शून्य से, तत्व कोई भी एक्सप्रेशन |
| dictionary | `{ "naam": "Asha" }` | स्ट्रिंग कुंजियाँ; `d["naam"]` पढ़ता और लिखता है |
| function | `kaam (a) { ... }` | प्रथम-श्रेणी मान, अपने बनने वाले स्कोप को याद रखता है |

**अभी तय करने लायक अर्थ:** `==` और `!=` कभी टाइप नहीं बदलते (`1 == "1"` का मान `jhooth` है); `<`, `<=`, `>`, `>=` सिर्फ़ दो संख्याएँ या दो स्ट्रिंग लेते हैं; सीमा के बाहर का इंडेक्स रनटाइम त्रुटि है, `undefined` नहीं; फ़ंक्शन अपने ब्लॉक में ऊपर उठा लिए जाते हैं, ताकि वे एक-दूसरे को बुला सकें।

## ऑपरेटर, सबसे कम से सबसे ज़्यादा प्राथमिकता तक

| स्तर | ऑपरेटर | साहचर्य |
| --- | --- | --- |
| 1 | `=` `+=` `-=` `*=` `/=` `%=` | दाएँ |
| 2 | `\|\|` `ya` | बाएँ, शॉर्ट-सर्किट |
| 3 | `&&` `aur` | बाएँ, शॉर्ट-सर्किट |
| 4 | `==` `!=` | बाएँ |
| 5 | `<` `<=` `>` `>=` | बाएँ |
| 6 | `+` `-` | बाएँ |
| 7 | `*` `/` `%` | बाएँ |
| 8 | एकल `!` `nahi` `-` | दाएँ |
| 9 | कॉल `f(x)`, इंडेक्स `a[i]` | बाएँ |

`&&` और `||` बूलियन लौटाते हैं और शॉर्ट-सर्किट करते हैं।

## व्याकरण (EBNF)

```ebnf
program     = { declaration } EOF ;
declaration = varDecl | funcDecl | statement ;
varDecl     = ( "rakho" | "pakka" ) IDENT [ "=" expression ] ";" ;
funcDecl    = "kaam" IDENT "(" [ params ] ")" block ;
params      = IDENT { "," IDENT } ;

statement   = exprStmt | ifStmt | whileStmt | forStmt
            | returnStmt | "ruko" ";" | "agla" ";" | block | ";" ;
ifStmt      = "agar" "(" expression ")" statement [ "warna" statement ] ;
whileStmt   = "jabtak" "(" expression ")" statement ;
forStmt     = "chalo" "(" ( varDecl | exprStmt | ";" )
                          [ expression ] ";" [ expression ] ")" statement ;
returnStmt  = "wapas" [ expression ] ";" ;
block       = "{" { declaration } "}" ;
exprStmt    = expression ";" ;

expression  = assignment ;
assignment  = ( IDENT | postfix "[" expression "]" ) assignOp assignment | logicOr ;
logicOr     = logicAnd { ( "||" | "ya" ) logicAnd } ;
logicAnd    = equality { ( "&&" | "aur" ) equality } ;
equality    = comparison { ( "==" | "!=" ) comparison } ;
comparison  = term { ( "<" | "<=" | ">" | ">=" ) term } ;
term        = factor { ( "+" | "-" ) factor } ;
factor      = unary { ( "*" | "/" | "%" ) unary } ;
unary       = ( "!" | "nahi" | "-" ) unary | postfix ;
postfix     = primary { "(" [ args ] ")" | "[" expression "]" } ;
primary     = NUMBER | STRING | "sach" | "jhooth" | "khaali" | IDENT
            | "(" expression ")" | listLit | dictLit | funcExpr ;
listLit     = "[" [ expression { "," expression } [ "," ] ] "]" ;
dictLit     = "{" [ pair { "," pair } [ "," ] ] "}" ;
pair        = ( STRING | IDENT ) ":" expression ;
funcExpr    = "kaam" "(" [ params ] ")" block ;
```

**रन के समय:** शून्य से भाग या शेषफल त्रुटि है (E0403)। `!`, `&&` और `||` के ऑपरेंड बूलियन होने चाहिए (E0405)। `==` सूचियों, शब्दकोशों और फ़ंक्शनों की तुलना पहचान से करता है। `chalo` लूप का वेरिएबल सभी चक्करों में साझा एक ही बाइंडिंग है। नाम अपनी घोषणा के बाद से दिखता है (फ़ंक्शन अपने ब्लॉक की शुरुआत से); मान मिलने से पहले उस तक पहुँचना E0406 है।

`rakho x;` से `x` को `khaali` मान मिलता है। `pakka` को शुरुआती मान चाहिए (E0206)। `agar`, `warna`, `jabtak` या `chalo` का हिस्सा एक स्टेटमेंट होता है, इसलिए वहाँ घोषणा के लिए ब्लॉक चाहिए (E0207)। नेस्टिंग 256 स्तर तक सीमित है (E0209)।

`warna agar` के लिए कोई ख़ास नियम नहीं चाहिए: `warna` के बाद एक स्टेटमेंट आता है, और वह स्टेटमेंट `ifStmt` है। `{` से शुरू होने वाला स्टेटमेंट ब्लॉक होता है, जैसे JavaScript में; शब्दकोश लिटरल को कोष्ठक में रखें या किसी वेरिएबल में डालें।

## अंतर्निहित फ़ंक्शन (MVP)

| नाम | व्यवहार |
| --- | --- |
| `bolo(a, b, ...)` | मानों को खाली जगह से अलग करके छापता है, फिर नई लाइन |
| `suno(prompt)` | प्रॉम्प्ट छापता है, एक लाइन पढ़ता है और उसे स्ट्रिंग के रूप में लौटाता है |
| `lambai(x)` | स्ट्रिंग, सूची या शब्दकोश की लंबाई |
| `joro(list, x)` | सूची में `x` जोड़ता है |
| `nikalo(list)` | आख़िरी तत्व निकालकर लौटाता है |
| `sankhya(x)` | स्ट्रिंग को संख्या में बदलता है; अमान्य हो तो त्रुटि |
| `shabd(x)` | किसी भी मान को उसके स्ट्रिंग रूप में बदलता है (इन मानों के लिए `sach`, `jhooth`, `khaali`) |
| `prakar(x)` | टाइप का नाम स्ट्रिंग के रूप में: `sankhya`, `shabd`, `bool`, `khaali`, `soochi`, `kosh`, `kaam` |

बूलियन और null `sach`, `jhooth` और `khaali` के रूप में छपते हैं; यह रूपांतरण सिर्फ़ `shabd` करता है, वेरिएबल पढ़ना कभी नहीं (दोष 7 और 8)।

### संग्रह, स्ट्रिंग और रूपांतरण

- सूची या स्ट्रिंग का इंडेक्स 0 से लंबाई - 1 तक की पूर्ण संख्या है; इससे बाहर E0410, दूसरा टाइप E0411। सूची के इंडेक्स को मान देने से तत्व बदलता है, सूची कभी बढ़ती नहीं।
- शब्दकोश की कुंजियाँ स्ट्रिंग होती हैं (वरना E0411)। जो कुंजी मौजूद नहीं, उसे पढ़ने पर `khaali` मिलता है; उसमें लिखने पर कुंजी जुड़ जाती है। लिटरल में दोहराई गई कुंजी का आख़िरी मान रहता है।
- स्ट्रिंग में इंडेक्स लग सकता है पर उसे बदला नहीं जा सकता (E0413)। इंडेक्स और `lambai` Unicode कोड पॉइंट गिनते हैं।
- `a[i] += x` में `a` और `i` एक ही बार निकाले जाते हैं।
- सूचियाँ `[1, "a"]` और शब्दकोश `{"k": 1}` के रूप में, डालने के क्रम में छपते हैं, स्ट्रिंग उद्धरण चिह्नों और एस्केप के साथ। अपने ही अंदर रखा संग्रह `[...]` या `{...}` के रूप में छपता है।
- खाली सूची पर `nikalo` E0414 है।
- `sankhya` एक स्ट्रिंग लेता है: वैकल्पिक `-`, अंक और वैकल्पिक दशमलव भाग; आस-पास की खाली जगह नज़रअंदाज़ होती है। कोई और पाठ E0415 है। अंतर्निहित फ़ंक्शन को गलत टाइप देना E0416 है।
- `suno` अपना प्रॉम्प्ट होस्ट को देता है और लाइन को बिना लाइन-अंत के लौटाता है; इनपुट खत्म होने पर `""` लौटाता है।

## उदाहरण

**पहला प्रोग्राम**

```hing
bolo("Namaste, duniya!");
```

**वेरिएबल, स्थिरांक और टाइप**

```hing
rakho naam = "Asha";
rakho umar = 25;
pakka PI = 3.14159;
rakho student = sach;
rakho kuch_nahi = khaali;
bolo(naam, umar, student, prakar(umar));   // Asha 25 sach sankhya
```

**शर्तें**

```hing
rakho marks = 82;
agar (marks >= 90) {
    bolo("A");
} warna agar (marks >= 75) {
    bolo("B");
} warna {
    bolo("C");
}
```

**लूप**

```hing
rakho i = 1;
jabtak (i <= 5) {
    agar (i == 4) { ruko; }
    bolo(i);
    i += 1;
}

chalo (rakho j = 0; j < 3; j += 1) {
    agar (j == 1) { agla; }
    bolo("j =", j);
}
```

**फ़ंक्शन, रिकर्शन और क्लोज़र**

```hing
kaam jodo(a, b) { wapas a + b; }
bolo(jodo(2, 3));                       // 5

kaam factorial(n) {
    agar (n <= 1) { wapas 1; }
    wapas n * factorial(n-1);           // works: '-' is never part of a number
}
bolo(factorial(5));                     // 120

kaam counter() {
    rakho c = 0;
    wapas kaam () { c += 1; wapas c; };
}
rakho gino = counter();
gino();
bolo(gino());                           // 2
```

**सूचियाँ और शब्दकोश**

```hing
rakho fal = ["aam", "kela", 1 + 2];     // elements are full expressions
fal[0] = "seb";                         // index assignment works
joro(fal, "angoor");
bolo(lambai(fal), fal[1]);              // 4 kela

rakho chhatra = { "naam": "Ravi", "shehar": "Pune" };
chhatra["umar"] = 21;
bolo(chhatra["naam"], lambai(chhatra));  // Ravi 3
```

**इनपुट और आउटपुट**

```hing
rakho naam = suno("Aapka naam? ");
rakho saal = sankhya(suno("Janm ka saal? "));
bolo("Namaste " + naam + ", umar kareeb", 2026 - saal);
```

**FizzBuzz**

```hing
chalo (rakho n = 1; n <= 15; n += 1) {
    agar (n % 15 == 0)     { bolo("FizzBuzz"); }
    warna agar (n % 3 == 0) { bolo("Fizz"); }
    warna agar (n % 5 == 0) { bolo("Buzz"); }
    warna                  { bolo(n); }
}
```

## त्रुटि संदेश

हर डायग्नोस्टिक में कोड, फ़ाइल, लाइन और कॉलम होते हैं, और वह सोर्स लाइन को `^` निशान के साथ दिखाता है। कमांड लाइन पर संदेश दो भाषाओं में होते हैं: पहले Hinglish, फिर कोष्ठक में सरल अंग्रेज़ी, जिसे `--lang` से चुना जा सकता है।

```text
Galti E0301 [naam nahi mila] at kaam.hing:3:9
    bolo(totl);
         ^^^^
'totl' declare nahi hua (undefined variable). Kya aapka matlab 'total' tha?
```

`--lang=hi` के साथ जगह और कॉल ट्रेस भी Hinglish में होते हैं (`yahan: kaam.hing:3:9`)।
वेबसाइट के अंग्रेज़ी पेजों पर प्लेग्राउंड डिफ़ॉल्ट रूप से यही इस्तेमाल करता है।

हर संदेश का देवनागरी हिन्दी रूप भी है, जिसे लाइब्रेरी में `lang: 'deva'` से चुना जाता है।
वेबसाइट के हिन्दी पेज उसे इस्तेमाल करते हैं; कमांड लाइन उसे उपलब्ध नहीं कराती।

REPL (`hinglish repl`) में किसी प्रविष्टि का आख़िरी `;` छोड़ा जा सकता है। फ़ाइलों में वह अब भी ज़रूरी है।
